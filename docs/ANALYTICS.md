# Nebula Flow v1.6.0 — 本地统计说明

## 指标口径
- 活跃时间：页面可见、Canvas 正常且动画运行时累计；后台页、暂停状态不累计。
- 会话数：同一浏览器当前站点每次打开网页加一。
- 场景偏好：每个场景的实际活跃时间。
- 粒子当前数：引擎 `particles.length`；可见粒子数：本帧实际通过视口边界检查并参与绘制的粒子数。
- 粒子峰值/平均值：每次完成渲染后采样；各场景数据仅在该场景活跃时累计。
- 创建/移除总量：按 `layout()` 中真实数组分配与截断计数；场景切换复用已有粒子，不会虚增创建数；reseed 会计入旧对象移除和新对象创建。
- 1% Low FPS：最近最多 600 帧中最慢 1% 帧的平均 FPS；P95/P99 为同一帧时间窗口的分位数。
- 卡顿帧：帧时间超过 33.333ms；低帧率帧：EMA FPS 低于 30。
- Canvas 像素数：实际 backing-store 宽 × 高；DPR 展示浏览器设备像素比，不等于内部渲染缩放因子。
- 性能：累计平均 FPS、绘制/模拟耗时；帧时间窗口保留最近 600 帧，避免长期存储无限增长。

## 隐私与资源开销
统计写入 localStorage 键 `nebula_flow_v16_stats`。不发起网络统计请求，不采集 IP、账号、设备 ID 或精确位置。不跨设备同步。清理站点数据会一并清除统计。支持 JSON/CSV 导出和清空。存储不可用时降级为本次页面内存数据并提示。帧时间窗口最多 600 个数字，统计 UI 只在每秒刷新，不在每个动画帧更新 DOM。

## 平台隔离
统计仅在普通浏览器页面开启。Wallpaper Engine 模式不启动统计、不显示统计入口、不改变其原生属性设置。

## 验收边界
粒子数量、布局分配与绘制可见数来自引擎真实状态；FPS、帧时间来自动画调度帧。浏览器未提供可靠统一的跨平台 GPU/系统内存计数，因此不虚构 GPU 利用率或系统内存。正式发布前仍须在 Chrome、Edge、Safari 和真实移动设备核验抽屉滚动、键盘、触摸、导出下载、存储禁用、重置确认、长时间使用与暂停恢复。
