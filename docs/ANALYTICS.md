# Nebula Flow v1.6.0 — 本地统计说明

## 指标口径
- 活跃时间：页面可见、Canvas 正常且动画运行时累计；后台页、暂停状态不累计。
- 会话数：同一浏览器当前站点每次打开网页加一。
- 场景偏好：每个场景的实际活跃时间。
- 交互：轻触、拖动、脉冲、场景切换、巡演和随机场景。
- 性能：每次绘制时采样的 EMA FPS、渲染耗时和模拟耗时；平均 FPS 是样本算术平均，不等同于整段端到端帧率。

## 隐私
统计写入 localStorage 键 `nebula_flow_v16_stats`。不发起网络统计请求，不采集 IP、账号、设备 ID 或精确位置。不跨设备同步。清理站点数据会一并清除统计。支持 JSON/CSV 导出和清空。存储不可用时降级为本次页面内存数据并提示。

## 平台隔离
统计仅在普通浏览器页面开启。Wallpaper Engine 模式不启动统计、不显示统计入口、不改变其原生属性设置。

## 验收
静态 JS 语法、HTML ID、模板构建可在合并前验证。正式发布前仍须在 Chrome、Edge、Safari 和真实移动设备核验抽屉滚动、键盘、触摸、导出下载、存储禁用、重置确认、长时间使用与暂停恢复。
